# 宗师雏田短片动作路线对照

三组测试均使用源视频开头约3秒，输出设定为576×1024、24fps、73帧。角色全身与环境以参考01为准。

| 试验 | 输入与参数 | 观察 |
| --- | --- | --- |
| 首帧加骨架 | FL2VA、FunControl 2.0、骨架强度1.0、4步 | 人物开头缩小，灰棚变暗，数处手臂和落脚偏离原片。侧边平均RGB绝对差的逐帧中位数32.35/255。 |
| 对齐骨架 | 骨架统一放大1.186倍，平移以对齐原图取景。区域外参考原图，骨架强度1.35、4步 | 色调明显更接近原图，侧边色差中位数7.81/255。0.75秒仍漏掉原片的抬手，末尾手臂和身体重心仍有偏差。 |
| 原视频引导 | Ref2VA + AddGuide + Character Swap LoRA 1.05，4步。角色图控制衣装与场景，主脸05辅助身份 | 任务665bbca8-06f6-46a2-9ed0-5abf1b13cc38完成。开场手靠脸、0.75秒抬指、1.75秒双臂交错、2.25秒伸臂及结尾收臂均比骨架更接近原片。灰棚保留，关键帧未见原片蓝色地纹。人物比参考图的构图略小，背景有少量色调变化，脸眼仍有部分偏软。侧边色差中位数16.12/255。 |

工作流为ComfyUI API格式。输入文件位于当前ComfyUI的input/h3_image_motion_20261118。每组保留实际工作流、运行状态、任务记录与原生视频。同时间点对照图含人物脸部区域，裁切仅供查看。

原视频引导沿用项目根目录的《MiniMax_H3_高质量视频部署指南》、compare_exact_20261115/h3_api.json及相关实测记录。AddGuide读取源视频画面及音频，参考图作为图片条件。

原视频引导版输出为「宗师雏田_MiniMaxH3视频引导_3秒.mp4」。使用模型原生画面，封装时从原片复制AAC。实际解码73帧、24fps、3.041667秒，音视频起点均为0。同段对照从左到右是原片、对齐骨架版、H3原视频引导版。
