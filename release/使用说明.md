# H3 影栈 · 使用说明

> 2026-11-18 画质状态：576生成后超分的示例已被用户否决，脸与眼睛失真。工程链路测试通过，人物画质尚未验收；768原生20步也仍偏软；局部512人脸重建已得到细节更清楚的3秒实验候选，但遮挡帧需回退，尚未成为默认自动步骤。

一个把 MiniMax H3 视频模型包装成「点点点就能出片」的桌面程序。
不用打开 ComfyUI，不用连线，不用记参数。

---

## 一、第一次打开

双击 `H3影栈.exe` 即可。

程序会自己找 ComfyUI 并启动它，右上角那颗灯变成绿色、显示「引擎就绪」就能用了。
第一次启动大约要等 40–60 秒（在加载模型）。

如果显示「引擎未启动」，点右上角那个齿轮，把 **ComfyUI 安装位置** 改成你机器上的路径，
例如 `E:/.../ComfyUI-aki-v3`（就是包含 `python` 和 `ComfyUI` 两个文件夹的那一层），保存后重启程序。

**关闭程序时**：如果 ComfyUI 是本程序自己拉起的，会连同整个进程树一起自动停掉，不留后台残留；
如果是你自己在外面开的 ComfyUI，程序退出时**不会**去动它。

## 二、五种玩法

| | 玩法 | 要准备什么 | 适合做什么 |
|---|---|---|---|
| ① | 文生视频 | 一段文字 | 先试试手感，不需要任何素材 |
| ② | 图生视频 | 角色图（必填）+ 场景图（可选） | **最推荐**，让她在你的场景里做动作 |
| ③ | 视频参考 | 1 段短视频 + 角色图 + 场景图 | 照着别人的动作重画一遍，人物和背景都换成你的 |
| ④ | 角色替换 | 1 段视频 + 角色图 + 场景图 | 把视频里的人整段换成你的角色 |
| ⑤ | 姿态控制 | 1 段视频 + 角色图 | 视频驱动角色替换；H3固定流程支持分割、固定背景、接缝选择、断点续接与片段返修 |

新手建议从 **② 图生视频** 开始：传一张全身、正面、背景干净的图，写一句「她随节奏跳舞」，
点开始生成，11 分钟左右出片。

**角色图和场景图是两个独立的框**，各自都能逐张添加（点缩略图右边的「＋ 继续加」）：

| 框 | 放什么 | 上限 |
|---|---|---|
| 角色图 | 同一个角色的全身正面、头肩特写、侧身等多角度 | ②③④最多4张；⑤全身1张、主脸1张、辅助角度2张 |
| 场景图 | 背景/环境参考，决定她站在哪、光从哪来 | 其他模式3张；⑤最多2张 |

只放角色图时，② 就直接拿它当视频第 1 帧让她动起来；
再加上场景图，就会切到「让角色进到场景里做动作」的路线。

## 三、关于 ④ 角色替换（主打功能）

④使用原有角色替换路线；⑤的H3固定流程也支持完整视频处理：

1. 把整段视频拖进来，程序自动按 10 秒切段
2. **角色图**框里放全身正面（定长相、发型、服装），想更像再加一张头肩特写
3. **场景图**框里放背景（定环境、光线和色调），不放就沿用原片的背景
4. 点开始生成

> 程序会自动把 `<Picture 1..k>`（角色）和 `<Picture k+1..>`（场景）写进提示词，
> 不用你自己记编号语法。

程序会逐段生成、自动拼接、最后把原视频的音轨挂回去。
34 秒的视频大约 1 小时 45 分钟。

**注意**：场景图会直接决定成片的背景。想要纯白摄影棚，第 2 张就放白底图；
放的是庭院、花瓣，成片背景也会跟着变。

## 四、几个实用说明

- **看进度**：右栏任务卡片上有进度条、当前阶段（加载模型 / 采样中第几步）和「还剩多少分钟」。
  进度会一直往前走，不会卡在 0%。
- **中途取消**：任务卡片上点「取消」。
- **成品在哪**：所有成品都会存到「成品文件夹」，点右上角按钮直接打开。
- **删除作品**：右侧作品列表里，鼠标悬停在某条作品上会出现「✕」，点它确认后即从磁盘删除。
- **批量删除**：作品标题旁点「批量」进入批量模式——点条目勾选（或点「全选」），再点「删 N」
  一次清掉多个；点「✕」退出批量模式。
  （旧版本生成的「两份副本」——文件名里带 `_00001_` 的那份是引擎原件，内容和成品一样，
  现在可以直接删掉，新版本不会再产生双份。）
- **质量词**：默认收起，里面是写死的画质要求（皮肤纹理、构图完整、不糊脸、不多手多脚等）。
  一般不用动；想强调某种质感（如胶片颗粒）可以展开后自己加一句。
- **高级参数**：默认收起，展开后可以填：
  - **宽 / 高**：留空用上面的比例预设；填了会吸附到 32 的倍数。
  - **帧数**：留空用「时长」预设；填了会吸附到 17k+5（124≈5 秒、243≈10 秒、362≈15 秒）。
  - **种子**：填同一个数字可以复现同一段画面；留空每次都不一样。
- **调整画质**：
  - 精细度「标准」= 4 步 + 加速 LoRA，快；「高质」= 20 步、关加速，慢约 5 倍。
  - 画面比例多选「竖屏高清」= 768×1344，比「竖屏」清晰一点，但耗时接近翻倍。
- **参考图精度**（③④）：`match` 快；`max` 用 2048 短边跑参考图，身份更像但慢数倍。
- **时长**：单次最长 15 秒。要做更长的片子，生成多段再剪接。
- **⑤ 姿态控制：H3固定流程（2026-11-18）**：
  1. 选择「H3 · 固定流程」，上传动作视频及角色图。全身衣装参考放正面全身图，身份主脸单独放清晰正面头部；辅助角度最多2张，分别用于左右侧脸等。
  2. 固定背景可选「灰棚背景」或「独立背景图」。灰棚从角色图空白边缘估计，适合干净背景；独立背景图使用第1张场景图，按画幅等比裁切。复杂环境推荐提供独立空背景图。
  3. 生成分辨率选择短边576或768，按源片比例适配并对齐32像素，保持人物比例。先选「先试3秒」，确认后改「整段」。
  4. 采样质量可选4步快速/20步高质；高质耗时明显增加，不保证修正动作或人体错误。参考图精度可选match/max，角色替换强度可选1.0/1.15/1.3。
  5. 增强输出选择原生尺寸或1080p超分。超分调用已安装的RealESRGAN_x2plus；它改善观感，不代表恢复原片真实细节。本固定流程输出24fps。
  6. 固定步骤：24fps时间线 → 73帧短段/12帧重叠 → H3视频引导 → SAM3人物分割 → 固定背景合成 → 可选逐段超分 → 接缝匹配 → 原音轨或静音 → 完整解码核验。
  7. 任务卡片显示当前阶段及真实采样步数。失败/取消后点「从断点继续」；重启后可在「流程记录 / 断点续接」找到任务，已完成片段会复用。
  8. 检查接缝预览及成片后，可以在流程记录中「指定片段返修」，填写该段补充要求。只重做选中段，再更新整片；原片段、参数及成片保存在过程目录的返修备份中。
  9. 成品在设置的成品目录；过程/状态/API图/结果/接缝预览放在其下的「过程」目录。完成代表技术核验通过，脸、衣装、鞋型、手脚与动作仍需人工验收。
  10. 依赖：ComfyUI需提供MiniMax H3、SAM3_VideoTrack等节点，模型库需包含SAM3权重；选择超分还需要RealESRGAN_x2plus。缺少时会在生成前提示，程序不会静默换模型。
- **其他引擎保留**：SCAIL-2使用源视频/角色人物遮罩驱动，原生16fps；当前只使用第一张角色图，16GB配置会把短边限制到512。旧H3使用视频参考或AddGuide视频引导；Wan为实验路线。界面参数存在不代表所有引擎都会采用全部参考图。
- **本轮验证范围**：576×1024、4步、3秒素材已真实跑通生成/分割/灰底/超分/1080×1920导出，原音轨保留；EXE接口、资源打包和缓存续接已验证。768原生和20步整片没有在本轮重跑。此前34秒试验的鞋型继承、手部和衣装漂移仍是需要检查的问题。

## 四点五、新电脑部署（release 全家桶）

release 目录里带了全套模型（`models/` 下约 62 GB：两个 20G 的视频模型 + 15G 文本编码器 +
LoRA 与 VAE）。在一台新电脑上从零开始只要两步：

1. **装一个基础 ComfyUI**：版本 ≥ **0.45.0**（更老的版本没有 MiniMax H3 节点）。
   官方便携版或整合包都行，不需要装任何插件、不需要下载任何模型。
2. **拷贝整个 release 文件夹**（exe + models 一起），双击 `H3影栈.exe` →
   设置里填 ComfyUI 位置 → 点 **「挂接自带模型包」** → 重启 ComfyUI（或重启本程序让它拉起）→ 完成。

「挂接」的原理：往 ComfyUI 根目录写一个 `extra_model_paths.yaml`，把 release/models
下的四个目录登记为 ComfyUI 的模型搜索路径——**不复制、不移动、不占用额外空间**。
拔掉 release 目录（或删掉 yaml）即可还原。

> 注：模型包里还带着 FunControl 姿态模型（4.2G，`model_patches/`），当前 ⑤ 不用它，留作骨架控制实验备用。
> ⑤提供多条路线；固定流程需要H3、SAM3及可选超分节点/权重，具体以该模式的依赖提示为准。

## 五、常见问题

**Q：点开始生成没反应？**
看右上角引擎灯。如果是灰的，点旁边的加号启动引擎。

**Q：生成失败了？**
任务卡片上会写原因。最常见的是显存不够 —— 关掉别的占显卡的软件（游戏、其他 AI 工具）再试。

**Q：能不能不用这个程序，直接开 ComfyUI？**
可以。工作流在 `ComfyUI/user/default/workflows/MiniMax_H3_五模式/` 目录下，
用 ComfyUI 打开就能看到，和程序里是同一套参数。

**Q：程序放在哪、会改我什么？**
程序本身不写注册表、不装服务。只在 `%APPDATA%\H3Studio` 存配置和临时素材。
删除这个文件夹就完全干净了。

## 六、技术参数（给想深入的人）

- 主模型：`minimax_h3_fl2va`（图生视频）/ `minimax_h3_ref2va`（参考/换人）
- 加速：4 步 turbo LoRA
- 默认画布：640×1120，24fps，124 帧（约 5.2 秒）
- 帧数需落在 17k+5 网格上：124 / 141 / … / 243 / 260 / …
- 换人模式：每段 243 帧、重叠 49 帧，后段丢弃重叠部分后拼接

## 2026-11-18 人脸质量补充

软件已增加独立身份主脸和辅助角度上传，明确五官与衣装的参考分工。原生高分辨率/更多采样步骤不保证修复小人脸。

局部人脸重建目前是实验脚本：单独512×512生成人脸，跟踪对齐后合成，并保护手部遮挡。3秒1080p候选的10/12/13帧保留原画面以避免重影；整体手部、颜色边缘和全角度稳定仍需人工验收。该阶段尚未接入EXE默认流程，也未替换完整34秒成片。

## 七、自然语言视频角色替换

⑥自然语言替换支持上传源视频、填写开始和结束秒数、填写两个目标人物描述，并分别绑定两组角色参考图。描述用于告诉模型目标人物的位置、外观和动作特征，程序会先裁切指定时间范围，再提交 H3 工作流并挂回原音轨。

示例：把 0 到 10 秒花田画面左侧的人替换为宗师雏田，把右侧的人替换为漂泊佩恩-萝莉道，保留花田、砖墙、鸽子、镜头运动和原音轨。

多人画面当前使用多参考图的整帧 H3 生成。目标描述会写入提示词，但模型不能保证把每组参考图始终锁定到指定人物位置。需要严格逐人物锁定时，下一阶段接入 SAM3 目标跟踪蒙版，对每个目标分别生成并合成。

自然语言替换支持单目标和多目标。只上传一组角色参考图时，在自然语言要求里写清楚目标人物即可，例如“把 5 到 8 秒画面中央的人替换成这个角色，保留其他人物和背景”。上传第二组参考图后，可以在目标 2 描述中补充第二个人，也可以直接在自然语言要求中说明。

自然语言替换中的参考图上传现在是通用参考入口，可以上传角色图、场景图、物体图或光线参考。自然语言要求负责说明每张参考图对应的用途。源视频固定位置的常见水印会在送入 H3 动作引导前进行预处理，避免水印被模型带入成片。

自然语言替换的参考图用途由提示词决定。例如上传角色图作为参考图1、场景图作为参考图2，然后写“参考图1替换人物，参考图2替换源视频场景，去除源水印，动作沿用视频”。程序会把两张图一起送入H3，并保留用户对人物、场景、物体和光线用途的说明。

自然语言替换新增生成分辨率选项：标准 832×480、高清 1024×576、超清 1280×720。精细度仍可选择标准 4 步或高质 20 步。高清和超清会增加显存占用与生成时间。

自然语言替换的分辨率档位使用专业名称：480p（832×480）、720p（1280×720）、1080p（1920×1080）、2K（2560×1440）、4K（3840×2160）。支持横屏和竖屏，竖屏会自动交换宽高。选择“自定义”后，可以在高级参数中输入自定义宽高，程序会自动吸附到 32 的倍数。

自然语言替换默认使用“两阶段”模式，一次点击自动完成两次生成。第一阶段只根据场景参考图重拍环境并保留源人物，第二阶段只根据角色参考图替换人物并锁定第一阶段场景，最后挂回源视频音轨。H3 会把分辨率吸附到安全网格，720p 竖屏通常输出约 736×1280。单阶段模式仍可在处理方式中手动选择。
